# Delegrix v0.2.0 — Goal-Driven Agent Orchestration

**Draft release notes — not published.** The feature branch implements the M1–M5 instruction contracts in [issue #2](https://github.com/GendByteMaster/Delegrix/issues/2). Package, CLI and Skill metadata are now 0.2.0 in the feature branch. No tag, publication or full runtime acceptance is implied.

## Highlights
- Goal Intelligence v2: measurable task-local outcome, scope and stable required/optional criteria, native-goal discovery and reuse without duplicated tasks.
- Lifecycle and evidence: pending, passed, failed, blocked and stale criteria; invalidate affected evidence and verify the integrated subject before completion.
- Criterion-linked delegation: bounded deliverables, dependency-ready waves, evidence-linked handoffs and optional schema v2 preflight with mandatory criterion coverage. Schema v1 remains supported.
- EngSense: optional, conditional engineering judgment for strategy, partitioning and recovery; no vendored modules or automatic installs.
- Bounded recovery: evidence-supported diagnosis, targeted repair, stop on no progress or oscillation; default two attempts per episode and four per goal subject to stricter policy.
- ForgeGuard and ForgeScope retain their policy and review responsibilities. The primary agent is responsible for accepting integrated evidence.

## Compatibility
The installed Skill remains portable and instruction-only. It does not provide a runtime, goal service, permission grant, external model call or background execution. Native capabilities and actual activation modes depend on the host. Existing CLI install, update, status and uninstall interfaces are unchanged. No companion repository is modified.
