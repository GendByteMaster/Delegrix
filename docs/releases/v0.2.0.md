# Delegrix v0.2.0 - Goal-Driven Agent Orchestration

Delegrix v0.2.0 introduces Goal Intelligence v2, criterion-driven delegation, adaptive engineering judgment, and evidence-based recovery for coding agents.

## What's New

- **Goal Intelligence v2** - measurable task-local goals, stable success criteria, and structured goal lifecycle management.
- **Native & Local Goal Management** - discover, reuse, or establish appropriate goal state based on host capabilities without duplicating tasks.
- **Goal-Driven Delegation** - criterion-linked worker assignments, dependency-ready execution, bounded ownership, and verified handoffs.
- **EngSense Integration** - optional engineering judgment for strategy, decomposition, and recovery.
- **Bounded Self-Correction** - evidence-supported diagnosis, finite repair budgets, and no-progress detection.
- **Evidence Lifecycle** - evidence tracking, invalidation, and revalidation after changes.
- **Completion Gate** - acceptance based on current evidence for all mandatory criteria and applicable review gates.
- **Preflight Schema v2** - goal-aware structural validation with backward compatibility for schema v1.
- **Release & CLI Improvements** - synchronized version management, release safeguards, and a Git checkout installation alternative when npm blocks Git dependencies.

## Ecosystem Integration

Delegrix integrates with [ForgeGuard](https://github.com/GendByteMaster/ForgeGuard), [ForgeScope](https://github.com/GendByteMaster/ForgeScope), and [EngSense](https://github.com/GendByteMaster/EngSense) while remaining independently usable as a portable, instruction-only Agent Skill. The primary agent retains responsibility for authorization, integration, and final acceptance.

## Compatibility

Designed for Codex, Claude Code, Cursor, and compatible Agent Skills environments. Delegrix does not supply its own execution runtime or grant worker permissions. Native goal management, Skill activation, and subagent execution depend on the host's capabilities. Further host-specific runtime validation is tracked in [issue #2](https://github.com/GendByteMaster/Delegrix/issues/2).

## Installation & Updates

**Requirements:** Node.js 18+ and Git (no npm registry publication required).

### Install

Install the tagged version for your preferred client:

```bash
# Codex
npx --yes github:GendByteMaster/Delegrix#v0.2.0 install --client codex --global

# Claude Code
npx --yes github:GendByteMaster/Delegrix#v0.2.0 install --client claude --global

# Cursor
npx --yes github:GendByteMaster/Delegrix#v0.2.0 install --client cursor --global

# All supported clients
npx --yes github:GendByteMaster/Delegrix#v0.2.0 install --client all --global
```

### Update an existing installation

```bash
npx --yes github:GendByteMaster/Delegrix#v0.2.0 update --client codex --global
npx --yes github:GendByteMaster/Delegrix#v0.2.0 update --client claude --global
npx --yes github:GendByteMaster/Delegrix#v0.2.0 update --client cursor --global
```

### Status, version and uninstall

```bash
# Inspect installed Skills
npx --yes github:GendByteMaster/Delegrix#v0.2.0 status --client all --global

# Check CLI version
npx --yes github:GendByteMaster/Delegrix#v0.2.0 --version

# Preview an update
npx --yes github:GendByteMaster/Delegrix#v0.2.0 update --client codex --global --dry-run

# Uninstall Codex Skill (only when desired)
npx --yes github:GendByteMaster/Delegrix#v0.2.0 uninstall --client codex --global
```

Use `--client claude`, `--client cursor`, or `--client all` for other targets. Use `install` for missing installations; `update` requires an existing managed Skill. Omit `--global` and run from your project directory for a project-local installation.

### Alternative: Git + Node.js (EALLOWGIT)

If npm blocks Git dependencies, clone the release directly without weakening npm security policy. Run these commands from your intended project directory.

**Windows PowerShell:**

```powershell
$src = Join-Path $env:TEMP ("delegrix-v020-" + [guid]::NewGuid().ToString("N"))
git clone --branch v0.2.0 --depth 1 https://github.com/GendByteMaster/Delegrix.git $src

# Choose install OR update
node "$src/bin/delegrix.js" install --client codex --global
# node "$src/bin/delegrix.js" update --client codex --global

node "$src/bin/delegrix.js" status --client codex --global
node "$src/bin/delegrix.js" --version
```

**Linux / macOS (bash):**

```bash
src="$(mktemp -d)"
git clone --branch v0.2.0 --depth 1 https://github.com/GendByteMaster/Delegrix.git "$src"

# Choose install OR update
node "$src/bin/delegrix.js" install --client codex --global
# node "$src/bin/delegrix.js" update --client codex --global

node "$src/bin/delegrix.js" status --client codex --global
node "$src/bin/delegrix.js" --version
```

The same client flags, project-local mode, dry-run and uninstall commands work with the direct Node.js CLI.

### Usage

Restart your agent session after installation or update. Invoke `$delegrix` in Codex or select the installed Delegrix Skill using your client's supported mechanism. Explicitly authorize any desired subagent delegation in the current task.

See the [official documentation](https://github.com/GendByteMaster/Delegrix#readme) for details.
