# Delegrix v0.1.0

Initial public Agent Skill for bounded, authorization-aware subagent delegation.

## Features
- Adaptive delegation with scoped worker contracts, exclusive write ownership, handoffs and verification.
- Offline JSON preflight (advisory only; never a substitute for live authorization).
- Auto-attempt installed ForgeGuard and ForgeScope instruction-level workflows with explicit activation reporting.
- Automatically define/reuse a measurable task-local Goal using ForgeGuard Goal Intelligence without spawning a new task.
- Codex, Claude Code and Cursor portable CLI installer, status and uninstall.
- Python scenario/packaging tests and Node CLI lifecycle tests on Linux and Windows.

## Limitations
- Delegrix is an instruction-only Skill, not a standalone agent runtime or model router.
- Real Codex subagent spawn/cancel and integrated worktree smoke tests must be proven in an authorized host before claiming runtime acceptance.
- npm registry publishing requires a configured NPM_TOKEN.
